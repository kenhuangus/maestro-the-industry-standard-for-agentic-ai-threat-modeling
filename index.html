The 10 Layers in One

One stack for the whole agent system — every component maps to a layer.

Definition CSA, 6 February 2025

  • MAESTRO expands to Multi-Agent Environment, Security, Threat, Risk, and Outcome — the CSA framework for threat modeling multi-agent and agentic AI systems.
  • v2.0 expands the stack from seven layers to ten, reorganized into three operational domains.
  • L1–L6 are the operational stack in Domains 1 and 2; L7–L10 run horizontally across all of them.

The 3 Domains

Ten layers, grouped the way agent systems are actually owned and run — aligned with the CSA AI Agent Reference Architecture (CSA, 2026).

Domains One line per domain

  • Domain 1 · Infrastructure, Intelligence & Knowledge (L1–L3): what the agent runs on, reasons with, and remembers — infrastructure (owner: CSP), cognitive core (owner: Model Provider), data, memory and knowledge (owner: Agent Owner).
  • Domain 2 · Environment & Execution (L4–L6): where the agent plans, runs, and reaches the world — orchestration (OSP), deployment and execution (CSP + OSP), and tools, application, environment and ecosystem (Tool Provider, per tool interface).
  • Domain 3 · Agency, Governance & Accountability (L7–L10), horizontal: identity and autonomy, safety and security, evaluation and observability, and governance — cutting across Domains 1 and 2, not stacked on top of them.

How to Use It: Six Steps

The v2 method (§10) — the same six steps, in order, every time. Start with one system.

Method MAESTRO v2.0, §10

  • Steps 1–2: decompose the system and map each component to the ten layers; then run layer-specific threat analysis from the §7 catalogs, documenting each threat in the 16-field template.
  • Steps 3–4: trace cross-layer propagation; select mitigations from the AICM, with ownership under the Agent 3SRM.
  • Steps 5–6: verify with behavioral test sets and drift thresholds — replay on any model, prompt, tool or policy change — then score and prioritize risk (§10.6).
